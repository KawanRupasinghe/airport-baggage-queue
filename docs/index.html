About · How to use · Verification

Choose the arrival rate, mean screening duration and number of identical stations. Press Start to run a single FIFO queue with exponential interarrival and service times. Pause or reset at any time. The simulation admits arrivals for 60 minutes, then drains the queue before reporting final statistics. Repeated runs are needed for confidence intervals; this single animation is not a statistical conclusion.

Reference trace: the deterministic test has arrivals at 0, 1 and 1.5 minutes, service times 3, 2 and 1 minute, and one station. Expected waits are 0, 2 and 3.5 minutes, with mean 1.8333 minutes. This test is shared with the Python unit tests.

Limitations: all inputs currently represent synthetic scenarios. Actual inspection durations will be incorporated after dataset cleaning and source checks. This is a queueing demonstration, not an operational safety recommendation.

All calculations run locally in your browser. No passenger data is transmitted.
