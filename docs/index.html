About · How to use · Verification

Choose the arrival rate, service-duration multiplier, number of identical stations, and empirical/exponential service model. Press Start to run a single FIFO queue with exponential interarrival times. Empirical mode samples observed baggage-check durations (n=162) with replacement. In baseline mode services are exponential with a 1-minute mean before scaling. Pause or reset at any time. The simulation admits arrivals for 60 minutes, then drains the queue before reporting final statistics. Repeated runs are needed for confidence intervals; this single animation is not a statistical conclusion.

Reference trace: the deterministic test has arrivals at 0, 1 and 1.5 minutes, service times 3, 2 and 1 minute, and one station. Expected waits are 0, 2 and 3.5 minutes, with mean 1.8333 minutes. This test is shared with the Python unit tests.

Limitations: arrival rates and pooled multi-station configuration are assumed rather than directly observed. The real data describe only selected manual baggage checks and may not represent all secondary checks. The animation is one run; notebook confidence intervals, not this animation, support scenario decisions. This is a queueing demonstration, not an operational safety recommendation.

Source: Rotterdam The Hague Airport Security Checkpoint Data (4TU.ResearchData; CC BY 4.0). Only screening durations are used; see dataset record for provenance.

All calculations run locally in your browser. No passenger data is transmitted.
