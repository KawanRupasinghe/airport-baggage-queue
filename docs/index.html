THE MODEL

Built on discrete-event simulation.

One shared first-in, first-out queue feeding multiple inspection stations. Poisson arrivals are assumed. Empirical service-time mode samples 162 measured baggage-check durations; exponential mode provides an M/M/c baseline.

VERIFICATION & RESPONSIBLE USE

Explore scenarios, not predictions.

Run reference trace uses arrivals at 0, 1 and 1.5 minutes and service times 3, 2 and 1 minutes on one station; expected waits: 0, 2 and 3.5 minutes (mean 1.8333 min).

This animation is one simulation realisation. Notebook replications provide uncertainty estimates. Arrival demand and queue configuration were not directly observed at the airport.

How to use this simulatorControls, reference test and interpreting the output⌄
  1. Choose an assumed arrival rate, number of stations, service-time model and service-time multiplier.
  2. Press Start simulation. Watch the waiting queue and inspection stations as simulation time advances. Use Pause/Resume or Reset at any point.
  3. Observe the five live statistics. The queue chart displays the sampled queue count from this particular run; it is not a confidence interval.
  4. Press Run reference trace to run a fixed three-passenger check: mean queue wait should be 1.833 minutes.
  5. Use the linked Python notebook for replicated experiments, uncertainty intervals and staffing comparisons; the browser animation alone does not validate a real airport.
